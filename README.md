# devsyth-arch: Ethical Hacking Tool Installer for Arch Linux

## Description
A powerful script to streamline the installation of ethical hacking tools on Arch Linux. Select your desired tools from the BlackArch repository with an interactive terminal checklist.

## Features
-   **Interactive Selection:** Choose tools using a spacebar-enabled checklist.
-   **BlackArch Integration:** Access a vast collection of ethical hacking tools.
-   **Automated Installation:** Handles repository setup and package installation.
-   **User-Friendly:** Simple and guided process.

## Usage
1.  **Download the script:**
    ```bash
    git clone https://github.com/devsynth-arch/Ethical-Hacking-Tool-Installer.git
    cd Ethical-Hacking-Tool-Installer
    ```
2.  **Make it executable:**
    ```bash
    chmod +x devsyth-arch
    ```
3.  **Run the script:**
    ```bash
    ./devsyth-arch
    ```
    Follow the on-screen prompts to select and install your desired tools.
